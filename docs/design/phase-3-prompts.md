## Prompt

Design a beautiful production mobile Vietnamese customer QR ordering menu for DineFlow "Bếp Nhà", continuing Artisanal Operations existing design system: pine #173e32, ivory #f8f7f3, chartreuse #d9edb0, Be Vietnam Pro and Newsreader editorial serif. Editorial compact welcome "Một bữa ngon, một khoảng vui." Search dish field, horizontally scrollable category pills Tất cả, Khai vị, Món chính, Đồ uống. Menu dish rows with photos or elegant honest image placeholders, name Gỏi cuốn tôm thịt 45.000đ, Cơm chiên hải sản 85.000đ, Trà sữa 35.000đ, Cháo nấm marked Hết món; circular add controls, no fake ratings/promotions. Bottom sticky cart "2 món · 120.000đ / Xem giỏ hàng" with safe-area spacing. Design implementable responsive web with accessible 44px buttons. Scope Phase 3: staff must open session before ordering; anonymous guests explicitly join active session, configure required size / optional toppings, quantity, note, checkout priced by backend, own order history with Chờ xác nhận. No payment/service-request/realtime buttons yet. Include useful visual guidance for modifier sheet and empty/unopened/error states in output text.

## Implementation

Use the mobile menu's editorial typography, ivory canvas, pine controls, category pills, dish rows and safe-area cart bar. Guest history exposes only the visitor's own orders. Require an explicit admission to the current staff-opened session. Required modifiers and unavailable options are enforced by the server. Checkout and order detail use the same visual language; no billing, kitchen actions or realtime claims in Phase 3.
